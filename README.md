## 🎯 Learning Philosophy

以构建系统化知识体系为目标，坚持学习、实践、总结与输出。

- **夯实基础（Fundamentals）**：重视基础理论，建立扎实的知识根基。
- **积累材料（Resources）**：收集、整理优质文献、教材、模型与数据。
- **掌握方法（Methods）**：学习科学的研究方法与分析技术。
- **培养思路（Thinking）**：注重逻辑推理、批判性思维与跨学科思考。
- **总结输出（Output）**：及时归纳、记录、实践，将知识转化为自己的能力。

### 2. Scientific Computing with Python

利用 Python 生态中的科学计算工具解决数学、统计学及专业领域问题。

#### 🔹 NumPy — Numerical Computing

- 数组与矩阵运算（Array & Matrix Operations）
- 线性代数模块（`numpy.linalg`）

#### 🔹 SymPy — Symbolic Mathematics

- 微积分模块（`sympy.integrals`）
- 离散数学模块（`sympy.discrete`）
- 方程求解模块（`sympy.solvers`）
- 矩阵模块（`sympy.matrices`）
- 统计学模块（`sympy.stats`）

#### 🔹 SciPy — Scientific Computing

- 数值积分模块（`scipy.integrate`）
- 线性代数模块（`scipy.linalg`）
- 优化模块（`scipy.optimize`）
- 统计学模块（`scipy.stats`）

#### 🔹 Statsmodels — Statistical Modeling

- 统计建模与推断
- 回归分析
- 时间序列分析
- 统计检验

## 📖 Scientific Computing: Quick Reference

根据实际问题选择合适的 Python 工具，而不是为了使用工具而使用工具。

### Mathematical Problems

| Problem | Recommended Libraries |
|:--|:--|
| 微积分与符号计算 | `SymPy` |
| 数值积分 | `SciPy` |
| 方程求解 | `SymPy` |
| 线性代数 | `NumPy` / `SciPy` / `SymPy` |
| 概率分布与统计计算 | `SciPy` / `SymPy` |
| 统计建模与推断 | `Statsmodels` |

### Library Selection Guide

| Library | Core Strength | Recommended Use |
|:--|:--|:--|
| **NumPy** | Numerical Arrays | 数组运算、矩阵计算、线性代数 |
| **SymPy** | Symbolic Mathematics | 符号运算、微积分、方程求解 |
| **SciPy** | Scientific Algorithms | 数值积分、优化、线性代数、统计计算 |
| **Statsmodels** | Statistical Inference | 回归分析、假设检验、统计建模 |
